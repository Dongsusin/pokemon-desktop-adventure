# 프렌들리숍 상품 데이터

2026년 11월 19일 기준 플레이 가능한 도구는 445종입니다. 배틀 도구 목록과 원작 분류를 합친 뒤 같은 품목은 하나로 셉니다.

- 챔피언스 아레나에서 판매하는 도구 344종과 업적 보상인 레전드플레이트를 포함합니다. 원본 이름을 데스크톱 게임의 기존 저장 ID에 대응시킵니다. [원본 도구 등록부](https://github.com/Dongsusin/pokemon-champions-ai-web/blob/1e6f63395bb1621002585ec1f9836daac033e9b4/src/data/shopData.js) · [고정한 품목 목록](shop-scope.json)
- 포획에 쓰는 볼 38종을 포함합니다. 히스이의 헤비볼처럼 실제로 별개의 볼은 따로 취급합니다.
- HP 회복, 기절 회복, 상태이상 치료, PP 회복에 쓰는 도구와 열매를 포함합니다. 일반 회복 분류 외의 품목은 원작에서 회복에 쓸 수 있는 완제품을 개별 등록합니다. [PokéAPI 분류](https://github.com/PokeAPI/pokeapi/tree/e98f2ad82fc61c46036689ecb10c3aa89d562d6b/data/v2/csv) · [작품별 가방 번호와 명칭](https://github.com/kwsch/PKHeX/tree/6c9583883c7551ac74a4b74180cead249d4277b8/PKHeX.Core)

## 가격

원작 포켓머니로 판매한 최근 가격을 우선하고, 상점 가격이 없는 품목은 PokéAPI의 도구 기준가를 사용합니다. 희귀품의 가격을 정하기 어려운 경우 데스크톱 가격을 적용합니다. 몬스터볼은 100코인, 상처약은 150코인, 마스터볼은 100,000코인입니다. 프렌들리숍 판매 시에는 구입가의 절반을 정수 코인으로 받습니다. [상점 가격 스냅샷](shop-offers.json)

프로젝트 최상위에서 `node tools/build-shop-catalog.mjs`를 실행하면 원천 자료와 품목 목록으로 게임 카탈로그를 재생성합니다. 게임 실행 중에는 네트워크 연결이 필요하지 않습니다.
