# 챔피언스 아레나 트레이너 도트

[Pokémon Champions Arena](https://pokemon-champions-area-web.co.kr/)가 사용하는 트레이너 도트를 원본 PNG 그대로 포함합니다. 원작의 정규 AI 238명, 팩토리 삐에로, 보스전 간부 2개 조합을 표시합니다. 랜스·란다와 아테나·아폴로는 원작처럼 각 인물의 그림을 나란히 표시합니다.
