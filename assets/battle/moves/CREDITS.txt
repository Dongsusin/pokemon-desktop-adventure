Creatures Inc. and GAME FREAK inc. Nothing here is re-licensed by this project. Names only, no contact details.
The project-wide credits are in CREDITS.txt at the project root (sections 2 and 6 cover the same sources).

Every file listed below was copied unmodified (byte-identical, checked by SHA-1) on 2026-10-14 for milestone M4
(battle look). Scaling, tinting and blending happen at run time only.


SOURCE GAME
   Copied from a local copy of the original source (resources),
   whose Graphics and Audio folders carry the Pokemon Essentials resources of the Korean fan game
   "Pokemon: Another Red" by YOUNG (Pokemon Essentials v21.1), the same game the rest of the asset pack comes from.
   The pack's assets/Data/PkmnAnimations.rxdata (1,532 animations) names its pictures by these exact file names:
   all 431 cel sheets it uses are here, and 157 of its 161 background / foreground pictures. Missing in the source
   game as well: "PRAS- Sketch and Lick", "PRAS- Darkness BG", "PRAS- White BG", "uwu".
   Engine: Pokemon Essentials, created by Poccil (Peter O.) and Maruno (full contributor list: root CREDITS.txt).
