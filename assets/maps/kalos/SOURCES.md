# 칼로스 타운맵

《포켓몬스터 X·Y》에서 타운맵을 열 때 보이는 320×210픽셀 화면을 사용합니다. 파란 표시는 도시·마을과 리그, 주황색 표시는 동굴이나 시설입니다. 지도 그림의 권리는 원작 권리자에게 있습니다. [원본 게임 화면](https://archives.bulbagarden.net/wiki/File:Kalos.png) · [포켓몬 공식 칼로스 소개](https://www.pokemon.co.jp/ex/xy/story/01.html)

도시와 마을 16곳, 포켓몬리그, 도로 22곳, 아쥐르만과 주요 명소를 표시했습니다. 도시와 명소의 핀은 게임 화면의 표식 중심, 도로의 핀은 해당 구간 중간에 놓았습니다. 프로스트케이브는 버들비마을 북동쪽의 주황색 표식에 있습니다. [장소별 지도 참조](https://www.serebii.net/pokearth/kalos/) · [한국어판 게임 지명](https://github.com/abcboy101/poke-corpus/blob/1df697e384e7d3ef5994c011151e6820f9fd839e/corpus/XY/ko_common.txt)

이동할 수 있는 장소는 모두 63곳입니다. 별도 표식이 없는 시설 9곳은 입구를 함께 사용합니다. 예를 들어 플레어단 비밀기지는 옥유마을에서, 이름없는 동굴은 포켓몬마을에서, 프렌드사파리와 배틀하우스는 기남시티에서 선택합니다. 미르시티와 기남시티 사이는 열차로 연결합니다. [포켓몬 X·Y 게임의 장소와 교통 표기](https://github.com/abcboy101/poke-corpus/blob/1df697e384e7d3ef5994c011151e6820f9fd839e/corpus/XY/ko_script.txt)
